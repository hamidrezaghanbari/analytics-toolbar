🧪 Inspector Toolbar - Page View Event Test

📋 Test Instructions

This page tests the new Page View event trigger functionality.

  1. Open the Inspector Toolbar (it should appear at the bottom right)
  2. In Step 1, select any Category and Event
  3. Select Page View from the Event Trigger dropdown
  4. Click Next - it should skip directly to Step 3 (Attributes)
  5. The Step 2 (Selectors) indicator should show as "Skipped"

✨ Expected Behavior

  • When "Page View" is selected: Step 1 → Step 3 (skip Step 2)
  • When "Click" or "Visible on screen" is selected: Step 1 → Step 2 → Step 3
  • Step 2 should be visually marked as "Skipped" when Page View is selected
  • Using Previous button from Step 3 should go back to Step 1 (not Step 2)
