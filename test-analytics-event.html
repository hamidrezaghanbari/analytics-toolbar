Web Analytics API Call Event Tester

Setup Instructions

Make sure to initialize the InspectorToolbar with debug mode enabled:

const toolbar = new InspectorToolbar({ debug: true, // Enable debug mode // ... other options });
Note: The toast notifications will only appear when debug mode is enabled!

Event Structure

Each event dispatched has the following structure:

new CustomEvent('WEBANALYTICS_API_CALL', { detail: { name: 'event_name', description: 'Event description', properties: { key1: 'value1', key2: 'value2', // ... more properties } } });
